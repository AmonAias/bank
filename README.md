# Банковский виджет операций

Проект предоставляет инструменты для работы с банковскими операциями, включая маскировку данных, фильтрацию и сортировку.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/AmonAias/bank/tree/feature/homework_10_1
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.

## Модуль `generators`

Модуль содержит генераторы и функции для обработки транзакций.

### `filter_by_currency(transactions, currency)`
Функция возвращает итератор, который выдаёт только те транзакции,
у которых код валюты совпадает с переданным значением.

**Пример использования:**
```python
usd_transactions = filter_by_currency(transactions, "USD")
for _ in range(2):
    print(next(usd_transactions))
